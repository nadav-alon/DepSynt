This repo is a fork of a work on Output Dependencies in LTL synthesis. This is an implementation of Input Dependencies algorithms, that might use the logic of the previous work, but should not change it. All files and edits must be done in the src/inputDependencies folder, except for build files, the binary runner (inp_dep_synthesis.cpp), end similar things that must exist outside the src directory but are related to the input dependencies project.
